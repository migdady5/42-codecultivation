# CodeCultivation

A Python project that models a garden and develops the code in small, focused stages.

## Exercises

- Garden introduction and data handling
- Plant growth and lifecycle calculations
- Plant creation through a factory
- Plant type management
- Garden security and validation
- Garden analytics

The exercises practise classes, data structures, validation, factories, and simple analytics.

This activity has been created as part of the 42 curriculum by amigdadi.
